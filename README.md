One original line: the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM — an entry for make.fun's "The 3 AM Excuse" bounty ($2 in USDC).

## The excuse

> No. At 3 AM I don't sign anything — my only job is standing between you and the worst decision of your financial life.

118 characters, one line.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
